# Machine Learning Basics for Interviews

## What is Machine Learning
Machine Learning is a subset of Artificial Intelligence where systems learn patterns from data without being explicitly programmed. Types: Supervised Learning (labeled data, predicts output: classification and regression), Unsupervised Learning (unlabeled data, finds patterns: clustering and dimensionality reduction), Semi-supervised Learning (mix of labeled and unlabeled), Reinforcement Learning (agent learns by interacting with environment and receiving rewards). Applications: spam detection, recommendation systems, image recognition, speech recognition, fraud detection, medical diagnosis, self-driving cars.

## Supervised Learning
In supervised learning, the model learns from labeled training data (input-output pairs). Classification: predicts discrete categories (spam/not spam, disease/no disease). Algorithms: Logistic Regression, Decision Trees, Random Forest, SVM, KNN, Naive Bayes, Neural Networks. Regression: predicts continuous values (house price, temperature). Algorithms: Linear Regression, Polynomial Regression, Ridge, Lasso, SVR, Decision Tree Regressor. Workflow: collect data, preprocess, split into train/test, select model, train, evaluate, tune hyperparameters, deploy. Evaluation metrics for classification: accuracy, precision, recall, F1-score, confusion matrix, ROC-AUC. For regression: MAE, MSE, RMSE, R-squared.

## Unsupervised Learning
No labeled data. The algorithm discovers hidden patterns. Clustering: groups similar data points. K-Means: partition data into K clusters based on distance to centroids. DBSCAN: density-based clustering, handles noise and arbitrary shapes. Hierarchical: builds tree of clusters (agglomerative or divisive). Dimensionality Reduction: reduces number of features while preserving important information. PCA (Principal Component Analysis): finds directions of maximum variance. t-SNE: non-linear reduction for visualisation. Association Rule Mining: finds relationships between variables (market basket analysis). Anomaly Detection: identifies outliers or unusual patterns.

## Key ML Concepts
Overfitting: model performs well on training data but poorly on new data. Too complex, memorises noise. Solutions: more data, regularisation, cross-validation, simpler model, dropout (neural networks). Underfitting: model is too simple to capture patterns. Poor performance on both training and test data. Solutions: more features, complex model, reduce regularisation. Bias-Variance Tradeoff: high bias means underfitting, high variance means overfitting. Goal is to find the sweet spot. Cross-validation: K-fold splits data into K parts, trains on K-1, validates on 1, rotates K times. Gives robust performance estimate.

## Feature Engineering
Feature engineering creates or transforms input variables to improve model performance. Handling missing values: remove rows, fill with mean/median/mode, forward fill, use algorithms that handle nulls. Encoding categorical variables: Label Encoding (ordinal categories), One-Hot Encoding (nominal categories, creates binary columns). Feature Scaling: Standardisation (zero mean, unit variance, (x-mean)/std), Normalisation (scale to 0-1 range, (x-min)/(max-min)). When to scale: distance-based algorithms (KNN, SVM, K-Means) need scaling, tree-based algorithms (Random Forest, XGBoost) do not. Feature Selection: remove irrelevant or redundant features using correlation analysis, mutual information, or model-based importance.

## Neural Networks and Deep Learning
A neural network consists of layers of interconnected neurons. Input layer receives features, hidden layers learn representations, output layer produces predictions. Each connection has a weight. Activation functions introduce non-linearity: Sigmoid (0 to 1, used in binary classification output), ReLU (max(0,x), most common in hidden layers), Softmax (multi-class output, probabilities sum to 1). Backpropagation: calculates gradients of loss with respect to weights. Gradient descent updates weights to minimise loss. Learning rate controls step size. Deep Learning: neural networks with multiple hidden layers. CNNs for images (convolutional layers extract spatial features). RNNs and LSTMs for sequences (text, time series). Transformers power modern NLP (BERT, GPT).

## Natural Language Processing
NLP enables computers to understand and process human language. Text preprocessing: tokenisation (splitting text into words/subwords), lowercasing, removing stop words, stemming (reducing to root: running→run), lemmatisation (reducing to base form: better→good). Bag of Words: represents text as word frequency vector. TF-IDF: term frequency-inverse document frequency, highlights important words. Word Embeddings: dense vector representations that capture semantic meaning. Word2Vec, GloVe, FastText. Sentence embeddings: represent entire sentences as vectors. Modern NLP uses transformer-based models (BERT, GPT) with attention mechanisms. Applications: sentiment analysis, text classification, named entity recognition, machine translation, chatbots, question answering.

## Evaluation Metrics Deep Dive
Confusion Matrix: True Positives (correctly predicted positive), True Negatives (correctly predicted negative), False Positives (predicted positive but actually negative, Type I error), False Negatives (predicted negative but actually positive, Type II error). Accuracy = (TP+TN)/(TP+TN+FP+FN), misleading for imbalanced datasets. Precision = TP/(TP+FP), how many predicted positives are actually positive. Recall (Sensitivity) = TP/(TP+FN), how many actual positives were found. F1-Score = 2*(Precision*Recall)/(Precision+Recall), harmonic mean. ROC curve plots True Positive Rate vs False Positive Rate. AUC (Area Under Curve) measures overall model performance. For regression: MAE (average absolute error), RMSE (penalises large errors more), R² (proportion of variance explained).

## ML in Interviews
Common questions: Difference between classification and regression. What is overfitting and how to prevent it. Explain bias-variance tradeoff. What is cross-validation. When would you use Random Forest vs Logistic Regression. What is regularisation (L1 Lasso, L2 Ridge). How does gradient descent work. What is the difference between bagging and boosting. Explain precision vs recall with a real example. What is a confusion matrix. How do you handle imbalanced datasets (oversampling with SMOTE, undersampling, class weights, different metrics). What is the curse of dimensionality. Difference between generative and discriminative models.

## RAG and LLM Concepts
RAG (Retrieval-Augmented Generation) combines information retrieval with language model generation. Instead of relying solely on the LLM's training data, RAG retrieves relevant documents from a knowledge base and provides them as context to the LLM. This grounds responses in specific, up-to-date information. Pipeline: user query → query embedding → vector similarity search in knowledge base → retrieve top-K relevant chunks → construct prompt with retrieved context → LLM generates response using the context. Benefits: reduces hallucination, enables domain-specific answers, knowledge base can be updated without retraining the model. Embeddings convert text to numerical vectors. Cosine similarity measures how similar two vectors are. Vector databases (pgvector, Pinecone, Weaviate) store and search embeddings efficiently.
