# Python Interview Preparation

## Python Basics
Python is a high-level, interpreted, dynamically typed programming language. It supports multiple paradigms: procedural, object-oriented, and functional. Python uses indentation for code blocks instead of braces. Variables do not need type declarations. Python is strongly typed but dynamically typed, meaning types are checked at runtime and implicit type conversions are limited. Everything in Python is an object, including integers, strings, and functions. Python uses garbage collection with reference counting and a cyclic garbage collector for memory management.

## Data Types and Structures
Built-in types: int (arbitrary precision), float, complex, str (immutable, Unicode), bool, None. Collections: list (mutable, ordered, allows duplicates), tuple (immutable, ordered), set (mutable, unordered, no duplicates), frozenset (immutable set), dict (mutable, key-value pairs, ordered since Python 3.7). List comprehension creates lists concisely: [x**2 for x in range(10) if x % 2 == 0]. Dict comprehension: {k: v for k, v in items}. Strings are immutable, so concatenation creates new strings. Use join for efficient concatenation. Slicing: list[start:stop:step].

## Functions and Decorators
Functions are first-class objects in Python. They can be assigned to variables, passed as arguments, and returned from other functions. *args collects positional arguments as a tuple. **kwargs collects keyword arguments as a dictionary. Lambda functions are anonymous single-expression functions. Decorators are functions that modify the behaviour of other functions. A decorator wraps a function and adds functionality without modifying the original code. Common decorators: @staticmethod (no self), @classmethod (receives class as first argument), @property (getter/setter pattern). functools.wraps preserves the wrapped function's metadata.

## OOP in Python
Classes define blueprints for objects. __init__ is the constructor. self refers to the current instance. Inheritance: a subclass inherits from a parent using class Child(Parent). Python supports multiple inheritance. Method Resolution Order (MRO) determines which method is called using C3 linearisation. super() calls the parent class method. Encapsulation: single underscore _var is a convention for protected, double underscore __var triggers name mangling for privacy. Polymorphism: same method name behaves differently based on the object. Abstract classes use the abc module: inherit from ABC and use @abstractmethod to define methods that subclasses must implement. Dunder methods: __str__ for string representation, __repr__ for debugging, __len__, __eq__, __lt__ for operator overloading.

## Exception Handling
try-except-else-finally: try contains risky code, except catches specific exceptions, else runs if no exception occurred, finally always runs. Catch specific exceptions instead of bare except. Common exceptions: ValueError, TypeError, KeyError, IndexError, FileNotFoundError, ZeroDivisionError. Raise custom exceptions using raise. Create custom exception classes by inheriting from Exception. Context managers (with statement) automatically handle setup and cleanup, commonly used for file operations. The __enter__ and __exit__ dunder methods implement the context manager protocol.

## Iterators and Generators
An iterator is an object implementing __iter__ and __next__ methods. iter() creates an iterator from an iterable. next() retrieves the next value. StopIteration signals the end. A generator is a function that uses yield to return values lazily, one at a time. Generators are memory-efficient for large datasets because they do not store all values in memory. Generator expressions use parentheses: (x**2 for x in range(1000000)). The yield keyword pauses the function and saves its state. itertools module provides powerful iterator utilities: chain, zip_longest, product, permutations, combinations, groupby.

## File Handling and Modules
Open files with open(filename, mode): r for read, w for write (overwrites), a for append, rb for binary read. Always use the with statement for automatic file closing. Read methods: read() reads entire file, readline() reads one line, readlines() returns list of lines. Write: write() writes a string, writelines() writes a list of strings. Modules: import entire module, from module import specific items, as for aliasing. __name__ == "__main__" checks if the file is run directly. Packages are directories with __init__.py. pip installs third-party packages. Virtual environments (venv) isolate project dependencies.

## Python Collections and Utilities
collections module: Counter counts hashable objects, defaultdict provides default values for missing keys, OrderedDict maintains insertion order (less needed since Python 3.7), namedtuple creates lightweight immutable classes, deque provides fast appends and pops from both ends. heapq: min-heap operations (heappush, heappop, nlargest, nsmallest). bisect: binary search on sorted lists. functools: reduce for accumulation, lru_cache for memoisation, partial for partial function application. copy: shallow copy (copy.copy) copies the object but not nested objects, deep copy (copy.deepcopy) copies everything recursively.

## Concurrency in Python
Threading: threads run in the same process, share memory, limited by GIL (Global Interpreter Lock) which allows only one thread to execute Python bytecode at a time. Good for IO-bound tasks. Multiprocessing: runs separate processes with their own memory and GIL. Good for CPU-bound tasks. asyncio: asynchronous programming with async/await for IO-bound tasks. Event loop manages coroutines. aiohttp for async HTTP requests. concurrent.futures provides ThreadPoolExecutor and ProcessPoolExecutor for simplified parallel execution. GIL makes pure Python threading unsuitable for CPU-intensive parallelism but does not affect IO-bound operations or C extensions.
