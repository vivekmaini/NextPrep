# C and C++ Interview Preparation

## C Language Basics
C is a procedural, low-level, compiled language widely used in systems programming. It provides direct access to memory through pointers. C uses static typing where every variable must have a declared type. The compilation process: preprocessing (macros, includes), compilation (source to assembly), assembly (assembly to object code), linking (combine object files into executable). Header files (.h) contain function declarations and macros. Source files (.c) contain implementations. The main function is the entry point. printf for output, scanf for input. Format specifiers: %d int, %f float, %c char, %s string, %ld long, %lf double, %p pointer, %x hexadecimal.

## Pointers
A pointer stores the memory address of another variable. Declaration: int *ptr. Address-of operator: &variable gives the address. Dereference operator: *ptr gives the value at the address. Pointer arithmetic: ptr + 1 moves to the next element of that type. Array name is a pointer to the first element. Null pointer: a pointer that points to nothing (NULL or 0). Dangling pointer: points to freed or invalid memory. Wild pointer: uninitialized pointer with garbage value. Void pointer (void *): generic pointer that can point to any type, must be cast before dereferencing. Double pointer (int **pp): pointer to a pointer, used for dynamic 2D arrays and modifying pointers in functions. Function pointers: pointers that store addresses of functions, used for callbacks.

## Memory Management in C
Stack memory: automatic allocation for local variables, freed when function returns. Heap memory: manual allocation using malloc, calloc, realloc, freed using free. malloc(size) allocates uninitialized memory. calloc(count, size) allocates zero-initialized memory. realloc(ptr, new_size) resizes previously allocated memory. Always check if malloc returns NULL (allocation failure). Always free heap memory to prevent memory leaks. Common errors: use after free, double free, buffer overflow, memory leak. Sizeof operator returns the size in bytes. Stack overflow occurs from deep recursion or large local arrays.

## Structures and Unions
Structure (struct) groups different data types together. Each member has its own memory. Size is the sum of member sizes plus padding for alignment. Union shares memory among members. Size equals the largest member. Only one member can hold a value at a time. Typedef creates aliases for types. Bit fields specify exact number of bits for struct members. Struct padding: compiler adds padding bytes for memory alignment. Use pragma pack to control padding. Self-referential structures contain a pointer to the same type, used for linked lists and trees. Enum defines named integer constants.

## C Preprocessor and Macros
Preprocessor directives are processed before compilation. #include includes header files. #define creates macros (text substitution). #ifdef, #ifndef, #endif for conditional compilation. #pragma for compiler-specific instructions. Macro pitfalls: no type checking, side effects with expressions (use parentheses around parameters), no debugging support. Inline functions are often preferred over macros for type safety. #define MAX(a,b) ((a) > (b) ? (a) : (b)) is a common macro pattern. Header guards (#ifndef HEADER_H) prevent multiple inclusion.

## C++ Object-Oriented Features
C++ adds OOP to C. Classes encapsulate data and methods. Access specifiers: public (accessible everywhere), private (only within class), protected (within class and derived classes). Constructor initialises objects. Destructor (~ClassName) cleans up resources. Copy constructor creates a copy: MyClass(const MyClass& other). Move constructor (C++11) transfers ownership: MyClass(MyClass&& other). Operator overloading: define custom behaviour for operators (+, -, ==, <<). Friend functions can access private members. This pointer points to the current object.

## C++ Inheritance and Polymorphism
Inheritance types: public (maintains access levels), private (all inherited as private), protected (public becomes protected). Multiple inheritance: a class inherits from multiple base classes. Diamond problem: ambiguity when two parent classes share a common grandparent. Solved with virtual inheritance. Virtual functions enable runtime polymorphism. Pure virtual function (= 0) makes a class abstract. Override keyword (C++11) ensures a function overrides a virtual function. Final keyword prevents further overriding or inheritance. RTTI (Runtime Type Information): dynamic_cast for safe downcasting, typeid for type checking.

## C++ STL (Standard Template Library)
Containers: vector (dynamic array, O(1) random access, O(n) insert), list (doubly linked, O(1) insert at known position), deque (double-ended queue), set (sorted unique elements, O(log n)), unordered_set (hash-based, O(1) average), map (sorted key-value, O(log n)), unordered_map (hash-based, O(1) average), stack, queue, priority_queue. Algorithms: sort, binary_search, lower_bound, upper_bound, find, count, reverse, max_element, min_element, accumulate, next_permutation. Iterators: begin(), end(), rbegin(), rend(). Pair and tuple for grouping values. String class with methods: length, substr, find, append, compare.

## C++ Smart Pointers and Modern Features
Smart pointers (C++11) manage heap memory automatically. unique_ptr: exclusive ownership, cannot be copied, only moved. shared_ptr: shared ownership using reference counting, destroyed when last shared_ptr is destroyed. weak_ptr: non-owning reference to shared_ptr, prevents circular references. Auto keyword deduces type from initialiser. Range-based for loop: for(auto& x : container). Lambda expressions: [capture](params) { body }. nullptr replaces NULL. constexpr for compile-time evaluation. Templates: generic programming for functions and classes that work with any type. Template specialisation for specific type behaviour.

## Common C/C++ Interview Questions
Difference between malloc and new: malloc is a C function returning void*, new is a C++ operator that calls constructor. Difference between struct and class in C++: only default access (struct is public, class is private). What is virtual destructor: ensures derived class destructor is called when deleting through base pointer. What is RAII: Resource Acquisition Is Initialization, acquire resources in constructor, release in destructor. Static keyword: in C, static local variable persists, static global/function has file scope. In C++, static member is shared across all instances. Volatile keyword: tells compiler the variable may change unexpectedly, prevents optimisation. Const correctness: const member functions do not modify object state.
